## 🎯 项目核心功能

### 🔍 实时检测系统
- **检测精度**: 93% mAP@0.5
- **处理速度**: 166.7 FPS
- **支持格式**: 图片、视频、实时流
- **检测类别**: 占道经营-固定摊位、占道经营-流动摊位

### 🧠 智能决策支持
- **模型**: DeepSeek-R1-32B
- **响应延迟**: ≤287ms
- **功能**: 法规解读、分类标准、治理建议
- **部署**: 本地化边缘部署

### 📊 数据可视化
- **实时统计**: 检测数量、趋势分析
- **历史数据**: 检测记录、结果回放
- **报表生成**: PDF/Excel导出
- **地图展示**: 检测位置可视化
